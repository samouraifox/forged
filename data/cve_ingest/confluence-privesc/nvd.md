**CVE ID:** CVE-2023-22515

**Description:** External attackers exploited a vulnerability in publicly accessible Confluence Data Center and Server instances to "create unauthorized Confluence administrator accounts and access Confluence instances." Atlassian Cloud is unaffected.

**CVSS Scores:**
- NIST CVSS 3.1: 9.8 CRITICAL (Vector: AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H)
- Atlassian CVSS 3.0: 10.0 CRITICAL (Vector: AV:N/AC:L/PR:N/UI:N/S:C/C:H/I:H/A:H)
- CVSS 4.0: Not yet assessed by NIST

**Weaknesses:**
- CWE-20: Improper Input Validation
- NVD-CWE-noinfo: Insufficient Information

**Affected Software Versions:**
- Confluence Data Center 8.0.0–8.3.2, 8.4.0–8.4.2, 8.5.0–8.5.1
- Confluence Server 8.0.0–8.3.2, 8.4.0–8.4.2, 8.5.0–8.5.1
