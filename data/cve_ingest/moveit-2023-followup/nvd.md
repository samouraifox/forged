## Description

MOVEit Transfer versions before specific thresholds contain SQL injection vulnerabilities. "SQL injection vulnerabilities have been found in the MOVEit Transfer web application that could allow an unauthenticated attacker to gain unauthorized access."

**Affected Versions:**
- Before 2021.0.7 (13.0.7)
- 2021.1.x before 2021.1.5 (13.1.5)
- 2022.0.x before 2022.0.5 (14.0.5)
- 2022.1.x before 2022.1.6 (14.1.6)
- 2023.0.x before 2023.0.2 (15.0.2)
