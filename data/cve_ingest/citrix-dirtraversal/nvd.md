## Vulnerability Overview

This critical vulnerability affects Citrix Application Delivery Controller (ADC) and Gateway versions 10.5, 11.1, 12.0, 12.1, and 13.0, allowing directory traversal attacks.

## CVSS Severity Scores

- **CVSS 3.1**: 9.8 CRITICAL
- **CVSS 2.0**: 7.5 HIGH
- **Vector (3.1)**: `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H`

## Weakness Classification

**CWE-22**: "Improper Limitation of a Pathname to a Restricted Directory ('Path Traversal')"
